# Multi-Modal AI

AI systems that handle text, images, audio, and video — vision-language models, diffusion, CLIP, cross-modal retrieval, and realtime voice.

- **Estimated study time:** ~70 minutes
- **Question count:** 32
- **Recommended order:** [cheatsheet](./cheatsheet.md) → [questions](./questions.md).
- **Prerequisites:** [LLM Fundamentals](../llm-fundamentals/), [Vector Databases & Embeddings](../vector-databases-embeddings/) (for cross-modal retrieval).

## Sub-areas covered
- VLMs (CLIP, ViT, LLaVA, GPT-4V, Gemini, Claude vision)
- Diffusion (DDPM/DDIM/DiT, Stable Diffusion, Flux, ControlNet)
- Multi-modal embeddings, VQA, OCR/layout, document understanding
- TTS / STT (Whisper)
- Frontier: end-to-end voice (GPT-4o realtime, Gemini Live), VAD, neural codecs, latency budgeting
