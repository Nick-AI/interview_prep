# AI Agents and Agentic Systems

AI agents that plan, use tools, and reason in loops — architectures, memory, multi-agent systems, and failure modes.

- **Estimated study time:** ~75 minutes
- **Question count:** 46
- **Recommended order:** [cheatsheet](./cheatsheet.md) → [questions](./questions.md).
- **Prerequisites:** [LLM Fundamentals](../llm-fundamentals/), [Prompt Engineering](../prompt-engineering/) (for ReAct and tool use).

## Sub-areas covered
- Agent loop, ReAct, Plan-and-Execute
- Tool use / function calling, MCP
- Memory (short-term, long-term, episodic), reflection
- Single vs multi-agent, orchestration
- Guardrails, sandboxing, human-in-the-loop, irreversible actions
- Frontier: coding agents (Claude Code, Cursor, Devin, SWE-Bench), frameworks (LangGraph, CrewAI, AutoGen, Swarm), browser tools, sandboxing (E2B, Modal, Firecracker)
