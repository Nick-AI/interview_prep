# Fine-Tuning and Model Adaptation

Adapting pre-trained LLMs to new domains or tasks — full fine-tuning, PEFT (LoRA/QLoRA), RLHF, modern preference optimization (DPO/IPO/KTO/ORPO/GRPO), model merging.

- **Estimated study time:** ~70 minutes
- **Question count:** 33
- **Recommended order:** [cheatsheet](./cheatsheet.md) → [questions](./questions.md).
- **Prerequisites:** [LLM Fundamentals](../llm-fundamentals/) (training basics), [Prompt Engineering](../prompt-engineering/) (when to choose what).

## Sub-areas covered
- Full FT vs PEFT (LoRA, QLoRA, prefix/prompt tuning, adapters)
- RLHF, instruction tuning, RLAIF
- Dataset preparation, hyperparameters, catastrophic forgetting
- Domain fine-tuning, continual pre-training, distillation
- Frontier: DPO, IPO, KTO, ORPO, GRPO, model merging (TIES, DARE, slerp), modern synthetic data
