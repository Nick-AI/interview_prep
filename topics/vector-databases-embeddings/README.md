# Vector Databases and Embeddings

Embedding models, vector representations, and similarity search infrastructure for semantic retrieval.

- **Estimated study time:** ~45 minutes
- **Question count:** 22
- **Recommended order:** [cheatsheet](./cheatsheet.md) → [questions](./questions.md).
- **Prerequisites:** Linear algebra basics (dot product, cosine).

## Sub-areas covered
- Embeddings: dense vs sparse, dimensionality, multimodal
- Distance metrics: cosine, dot product, L2
- Vector DBs and ANN indexes (HNSW, IVF, DiskANN)
- Hybrid search, metadata filtering, multi-tenancy
- Quantization, scaling, drift handling
