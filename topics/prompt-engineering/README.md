# Prompt Engineering

Designing prompts to elicit reliable, structured, and safe LLM behavior — from few-shot to chain-of-thought to defensive techniques to prompt caching.

- **Estimated study time:** ~60 minutes
- **Question count:** 34
- **Recommended order:** [cheatsheet](./cheatsheet.md) → [questions](./questions.md).
- **Prerequisites:** [LLM Fundamentals](../llm-fundamentals/) (especially sampling, system prompts).

## Sub-areas covered
- Few-shot, zero-shot, CoT, ToT, self-consistency, ReAct
- System prompts, role prompting, prompt chaining
- Structured output (JSON, XML, tool calling)
- Prompt injection defenses, jailbreaking
- Prompt caching (Anthropic, OpenAI, prefix caching)
- Failure modes, edge cases, multilingual
