# AI System Design

End-to-end AI system design: architecture, latency/cost tradeoffs, scaling, multi-tenancy, and reliability patterns.

- **Estimated study time:** ~80 minutes
- **Question count:** 38
- **Recommended order:** [cheatsheet](./cheatsheet.md) for patterns, then [questions](./questions.md) for design exercises.
- **Prerequisites:** [LLM Fundamentals](../llm-fundamentals/), [LLMOps](../llmops/), [RAG](../rag/), [Agents](../agents/).

## Sub-areas covered
- Per-domain designs (chatbot, doc Q&A, code review, moderation, recommendation, fraud, etc.)
- Latency vs quality tradeoffs, caching, fallbacks
- Multi-region, multi-tenant, capacity planning
- AI gateway, rate limiting, graceful degradation
- Frontier designs: coding-agent platform, realtime voice assistant
