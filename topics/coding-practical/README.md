# Coding and Practical Implementation

Hands-on coding tasks for AI engineering interviews. Each entry sketches the approach, libraries, and gotchas — not runnable code.

- **Estimated study time:** ~50 minutes
- **Question count:** 22 tasks
- **Recommended order:** [cheatsheet](./cheatsheet.md) for libs/patterns, then [questions](./questions.md) for individual tasks.
- **Prerequisites:** Python, [LLM Fundamentals](../llm-fundamentals/), [RAG](../rag/), [Agents](../agents/).

## Sub-areas covered
- RAG pipelines, agents, semantic search, chunking
- Prompt templates, evaluation pipelines, streaming
- Conversation memory, hallucination detection, retry/backoff
- Token counting, semantic caching, prompt-injection detection, guardrails
- Multi-agent collaboration

## Format note
This topic is **outline-only by design** — each entry sketches inputs/outputs, libraries, key steps, and gotchas without runnable code. The goal is interview clarity, not a tutorial repo.
