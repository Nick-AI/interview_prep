# Retrieval-Augmented Generation (RAG)

Retrieval-Augmented Generation: grounding LLM answers in external knowledge via chunking, embedding, search, and re-ranking.

- **Estimated study time:** ~75 minutes
- **Question count:** 42
- **Recommended order:** [cheatsheet](./cheatsheet.md) → [questions](./questions.md).
- **Prerequisites:** [Vector Databases & Embeddings](../vector-databases-embeddings/), [LLM Fundamentals](../llm-fundamentals/) (context window, attention).

## Sub-areas covered
- Pipeline architecture (chunk → embed → retrieve → rerank → generate)
- Chunking strategies, embedding models, hybrid search, re-ranking
- Advanced patterns: Agentic RAG, GraphRAG, Self-RAG, HyDE
- Multi-document, multi-hop, structured-data, multi-modal RAG
- Evaluation: faithfulness, context precision/recall, RAGAS/TruLens/Phoenix
- Frontier: long-context vs RAG, ColBERT/late interaction, cache-aware RAG
