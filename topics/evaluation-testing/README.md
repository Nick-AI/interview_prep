# Evaluation and Testing

Measuring LLM and AI-system quality with offline metrics, LLM-as-judge, red teaming, and continuous evaluation.

- **Estimated study time:** ~60 minutes
- **Question count:** 31
- **Recommended order:** [cheatsheet](./cheatsheet.md) → [questions](./questions.md).
- **Prerequisites:** [LLM Fundamentals](../llm-fundamentals/), [RAG](../rag/), [Agents](../agents/) (for end-to-end eval).

## Sub-areas covered
- Metrics (BLEU, ROUGE, BERTScore, G-Eval, faithfulness, RAGAS)
- LLM-as-judge, pairwise vs Likert, human eval
- Red teaming, adversarial testing, regression suites
- Benchmarks (MMLU, HumanEval, GSM8K, MMMU, SWE-Bench)
- Continuous eval, golden datasets, fairness audits
- Frontier: Inspect AI, Promptfoo, agent-trajectory eval
